# WORLD BRIDGE — WORLD 01

スマートフォン向けの英語学習ページです。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成する（例：`world-bridge-world01`）。
2. このフォルダの中身を、リポジトリの一番上にアップロードする。
3. **Settings → Pages → Deploy from a branch** を開く。
4. Branchを `main`、フォルダを `/ (root)` にして保存する。
5. 数分後に表示されるURLを開く。

## ファイル構成

- `index.html`：公開ページの入口
- `hero.png`：開始画面の画像
- `story.png`：ストーリー画面の画像
- `environment.png`：環境の画像
- `government.png`：governmentの画像
- `complete.png`：完了画面の画像
- `.nojekyll`：GitHub Pagesで画像を正しく読み込むための設定

画像ファイルはHTMLと同じ階層に置いてください。
